# Keyboard Shortcuts

Only the keys that differ from 1.40b23. Each says where it came from.

## Colonies Screen

| Key | Action |
|---|---|
| Q | Load BUILD.CFG into the queue of the colony under the pointer; with Shift, into every colony *(from 1.51)* |
| 0-9 | Load BUILD0.CFG - BUILD9.CFG the same way *(from 1.51)* |

## Build Screen (Construction Orders)

| Key | Action |
|---|---|
| Q | Load BUILD.CFG into the queue *(from 1.51)* |
| 0-9 | Load BUILD0.CFG - BUILD9.CFG into the queue *(from 1.51)* |
| B | BUY, or take the purchase back when already bought *(from 1.51)* |
| Alt+A, D | Replace all six designs with automatic ones *(from 1.51)* |

## Compared with 1.51

1.51 has more new keys (PageUp/PageDown animation speed, H in combat,
Lua scripts on the main screen's digits, config reloads). They
come here when their features do.
