# The lobby's font

`fusion-pixel-12px-proportional-zh_hans.ttf`: Fusion Pixel Font
(https://github.com/TakWolf/fusion-pixel-font), release 2026.10.25, 12 px,
proportional, the zh_hans variant (the variants differ only in the regional
forms of Han characters). It covers Latin with its accents, Greek,
Cyrillic, Chinese, Japanese and Korean; the lobby prints chat, game
descriptions and player names in it. Licence: SIL Open Font License 1.1
(`OFL.txt`), with the licences of the fonts it is built from in `LICENSES/`.
